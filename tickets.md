# Tickets com histórico

1. Rotina, manual (entrega inicial mais rápida, com débito técnico), faz o input de todos os tickets na base Vetorial.
2. Consulta de contexto parecidos com um ticket específico (inicialmente single modal, somente texto).
3. Leitura do ticket em questão e todos os similares, para gerar a sugestão (Banco Relacional)
4. Sugestão (Texto da sugestão, justificativa, apontamento [LLM retorna posição do texto em que justificativa pode ser encontrada]).
